# jyotish-engine

Deterministic Vedic astrology calculation engine.

- Astronomy: NASA JPL ephemerides (DE440 in production, DE421 offline fallback) via Skyfield.
- Every dependency is permissively licensed (MIT/BSD/Apache). No Swiss Ephemeris code is used.

See `../docs/ARCHITECTURE.md` for module layout and `../docs/ACCURACY.md` for validation results.
