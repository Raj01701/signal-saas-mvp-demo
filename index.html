About this demo

An honest note on what you're looking at.

Everything is real: Supabase Auth for accounts (or one-click guest access), Postgres for storage, and Node serverless functions at /api that verify each session and enforce roles on the server. Every account gets its own private workspace seeded with sample data, so nothing you change affects anyone else. The front end is deliberately framework-free to keep the demo small; a client build would use React / Next.js on the same backend.
